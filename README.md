## Overview

**ASCII Challenge** is a fascinating experiment that reveals the surprising gap between human perception and artificial intelligence. Create ASCII art and watch as even the world's most advanced AI models struggle to interpret what humans can instantly recognize.

## What is ASCII Challenge?

ASCII art uses characters to create images - simple shapes, faces, or objects that are immediately recognizable to humans. However, despite their sophistication, modern AI models often fail spectacularly at this seemingly simple task. This project demonstrates that fascinating weakness.

## Features

- **Interactive ASCII Art Creator** - Build your own ASCII art challenges
- **Multiple Font Styles** - Choose from various ASCII fonts
- **Instant Copy** - Copy your creations to clipboard with one click
- **AI Testing Ground** - Use your creations to test different AI models
- **Responsive Design** - Works seamlessly on desktop and mobile
- **Clean UI** - Built with Next.js, React, and Tailwind CSS

## Why It Matters

This simple test highlights an important truth about AI:
- **Visual Understanding Gap** - AIs excel at many tasks but struggle with spatial reasoning
- **Pattern Recognition Limits** - What's obvious to humans isn't always clear to AI
- **Future Development** - Understanding these weaknesses helps improve AI systems

## Getting Started

```bash
# Clone the repository
git clone https://github.com/Moussa-M/ascii-challenge.git

# Navigate to directory
cd ascii-challenge

# Install dependencies
pnpm install

# Run development server
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to see the app.

## Usage

1. Type or paste your text
2. Choose an ASCII font style
3. Copy the generated ASCII art
4. Test it with your favorite AI model
5. Watch AI struggle with what you can instantly see!
